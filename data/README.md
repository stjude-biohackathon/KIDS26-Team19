# Data sources and provenance

All data used here is **open access**. Nothing in this directory requires a dbGaP
application, a GDC token, or any credential, and nothing here is identifiable.

## TARGET-AML clinical (NCI GDC)

| | |
| --- | --- |
| Source | NCI Genomic Data Commons, project `TARGET-AML` |
| Endpoint | `https://api.gdc.cancer.gov/cases` (POST, no authentication) |
| Retrieved by | `src/fetch_target_aml.R` |
| Cohort size | 2,492 cases reported by GDC; 2,158 with usable follow-up time |
| Events | 742 deaths (34.4%) |
| Median follow-up | 3.47 years |
| License | NIH Genomic Data Sharing Policy; open-access tier, no restrictions on use |
| Citation | Bolouri et al., *Nat Med* 2018, doi:10.1038/nm.4439 |

Fields pulled: `submitter_id`, `demographic.vital_status`, `demographic.days_to_death`,
`demographic.gender`, `demographic.race`, `diagnoses.age_at_diagnosis`,
`diagnoses.days_to_last_follow_up`, `diagnoses.primary_diagnosis`.

### Why this cohort

TARGET-AML is the only large pediatric AML cohort that exposes patient-level survival
labels through a public API **and** has open-access molecular files on the same
subjects: 3,227 gene expression quantification, 806 masked somatic mutation, 800
methylation beta value, and 92 gene-level copy number files. That combination is what
an outcome-prediction model needs, and it is available without a data access request.

### Generated files

| File | Contents |
| --- | --- |
| `processed/target_aml_clinical.csv` | Flattened case records, one row per subject |
| `processed/target_aml_survival.csv` | Adds `time`, `event`, `age_years`, `age_group`; drops subjects without follow-up |
| `../results/target_aml_km_by_age.png` | Kaplan-Meier overall survival by age band |

Both CSVs are regenerated by re-running the script. It reuses the cached pull when
`processed/target_aml_clinical.csv` already exists, so a rerun costs nothing.

## Known limitations

- **334 of 2,492 cases (13.4%) have no usable follow-up time** and are dropped from the
  survival table. They are kept in the clinical CSV so the exclusion stays inspectable.
- **Age alone does not stratify survival in this cohort** (log-rank p = 0.48 across four
  age bands). This is a real result, not a bug, and it is the argument for the project:
  if age does not separate risk, molecular features have to.
- Subjects with more than one diagnosis record contribute only their first.
- Overall survival only. Event-free survival is recorded in the TARGET clinical
  supplements, not in the case-level API fields used here.
