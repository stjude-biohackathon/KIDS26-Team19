# Results

Everything here is regenerated by `./run_all.sh`. Figure captions, with the constraints that
must travel with each figure, are in `docs/`.

## Read the filename prefix

The corpus was scored by two independent routes, and the prefix says which one a file came
from. They are not interchangeable.

| Prefix | Route | Scale |
| --- | --- | --- |
| `corpus_` | array series matrices | 38 studies, 613 samples, 95 contrasts, 41 agents |
| `ncbi_` | NCBI-recomputed RNA-seq counts | 44 studies, 970 samples, 162 contrasts, 74 agents |
| `lsc18_` | both routes combined, rank-based | 254 contrasts, 75 studies |

Combined totals: **82 studies scored** (75 yielding at least one contrast), **1,583 samples**,
**257 contrasts**. The rank-based analysis uses 254 of the 257; three array contrasts fall
below the gene-coverage threshold.

## Tables

| File | Contents |
| --- | --- |
| `corpus_scan.csv` | Every downloaded series with its platform and whether it supports a treated/control design |
| `corpus_sample_scores.csv`, `ncbi_sample_scores.csv` | Per-sample scores, one row per GSM, with the harmonised agent and control flag |
| `corpus_drug_ranking.csv`, `ncbi_drug_ranking.csv` | Per-contrast weighted-sum effects in within-study SD |
| `lsc18_singscore_ranking.csv` | **The primary result.** 254 rank-based contrasts with effect, permutation P and BH q. Figure 3 is built from this. |
| `corpus_null_test.csv`, `ncbi_null_test.csv`, `null_survival_test.csv` | Permutation results per contrast |
| `*_null_draws.rds`, `singscore_tests.rds`, `null_survival_test.rds` | Raw permutation draws, so P values can be rechecked without rerunning |
| `ncbi_scores/` | Per-study intermediates from the resumable counts run. `.skip` marks a study that could not be scored. |

## Two cautions

**Effects are in within-study standard deviations, never raw score units.** The score inherits
its input's units, so raw values are not comparable across platforms or normalisations.

**`archive/` is superseded work, not an alternative view.** Every figure there carries a
burned-in `SUPERSEDED` watermark because a README does not travel with a PDF dragged into a
slide deck. `archive/pilot/` holds the first pass over 4 to 6 studies: those tables once sat
in this directory with nothing in the filename to distinguish them, and `drug_ranking.csv`
there has 20 contrasts where `corpus_drug_ranking.csv` has 95.
